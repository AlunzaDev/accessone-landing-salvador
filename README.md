# AccessOne El Salvador

Propuesta de landing local construida con Astro, React y TypeScript. La dirección visual es urbana, cálida y orientada a una experiencia de estacionamiento fluida.

## Desarrollo

```sh
npm install
npm run dev
npm run build
```

El contacto comercial fue confirmado para AccessOne El Salvador. La dirección, el horario y los datos legales del aviso de privacidad siguen pendientes de validación.
