# AccessOne Centroamérica

Propuesta de landing local construida con Astro, React y TypeScript. La dirección visual es urbana, cálida y orientada a una experiencia de estacionamiento fluida.

## Desarrollo

```sh
npm install
npm run dev
npm run build
```

Los datos de contacto son provisionales. No publicar sin sustituirlos por información oficial de AccessOne Centroamérica.
